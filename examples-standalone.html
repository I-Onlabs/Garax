🎮 Garax Simple Space Shooter

This is a complete working example built with Garax's infrastructure.

Controls: Arrow Keys or WASD to move | R to restart when game over

Objective: Avoid the falling red enemies. Your health is shown above your green spaceship. Survive as long as possible!

Features demonstrated:

  • Dependency Injection pattern
  • EventBus communication
  • Game loop (update/draw)
  • AABB collision detection
  • State management
  • Progressive difficulty
